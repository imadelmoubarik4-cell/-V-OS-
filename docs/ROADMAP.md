# Roadmap

| Phase | Scope | Exit condition |
| --- | --- | --- |
| Sprint 1 / A.1 | Repository and private upload queue | Source files are stored privately and every batch is tracked |
| Sprint 1 / A.2 | Inventory extraction and staging | 300+ documented candidates, provenance, duplicate decisions, and review records |
| Sprint 2 | Secure inventory foundation | Canonical inventory contract, role boundaries, audit fields, and controlled promotion path |
| Sprint 3 | Real VÁ Data | Inventory snapshots, menus, recipes, suppliers, wine, coffee, equipment, invoices, purchases, and deliveries are registered in one private review-first graph |
| Sprint 3.1 | Review and approval workflows | Every exact match is approved, every ambiguity remains explicitly unresolved, and no source evidence is lost |
| Sprint 4 | Operational automation | Stock counts, waste, purchasing, deliveries, service readiness, and business intelligence use reviewed VÁ data |
| Later | Atlas Brain and finance | Recommendations and forecasts derive only from trusted operating data |

Sprint 3 does not write historical July quantities into live stock. It does not promote costs, recipes, suppliers, invoices, or purchase lines without a recorded approval decision.

Work moves forward only when the preceding data contract and privacy boundary are verified.
