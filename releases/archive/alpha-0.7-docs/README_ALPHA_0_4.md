# Atlas Alpha 0.4.0 — Operations Intelligence

This is an incremental release built on Atlas Alpha 0.3.0.

## Changed files

Upload only these files, preserving the folder structure:

- `index.html`
- `assets/css/operations.css`
- `assets/js/operations.js`

Do not replace `config.js`, `recipes.js`, `recipes.css`, `modal.js`, SQL files, or logo files.

## Included

- New Operations Center navigation and workspace
- Service-readiness score
- Dynamic priorities generated from inventory, recipes and checklists
- Suggested purchasing grouped by supplier
- Estimated purchase cost and case rounding
- Mark-order-as-completed controls saved for the current day
- Opening and closing checklists saved on the current device for the current day
- Operations Center entry in Quick Actions and Service Mode
- Additional Operations items in Home / Today's Focus
- Light Atlas modal stabilization for Add Item and Recipe Editor
- Modal overlays now cover the sidebar correctly
- Lucide icons only; no interface emojis

## Deployment

Commit the three changed files to the repository. Netlify should publish automatically.
