# Atlas Alpha 0.6.0 — Business Intelligence

This release adds a dedicated Business Intelligence layer without replacing Alpha 0.5 functionality.

## Upload only

- `index.html`
- `assets/css/business.css`
- `assets/js/business.js`

Keep all existing configuration, Recipes, Operations, Brain, modal, SQL and logo files unchanged.

## Included

- Business health score based on service readiness and data completeness
- Inventory valuation and working-capital concentration
- Purchasing spend by selected period
- Suggested order exposure
- Recipe margin and cost-per-serving analysis
- Supplier spend and purchasing concentration
- Inventory value by category
- Six-month purchasing trend
- Actionable business-data recommendations
- Honest data-coverage status for sales, bookings and labour

No database migration is required.
