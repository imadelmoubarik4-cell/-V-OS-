# Atlas Alpha 0.5.0 — Atlas Brain

This release extends the current Alpha 0.4 baseline. It does not replace Inventory, Recipes, Purchasing, Operations Center, authentication, configuration, or database files.

## Upload

Upload these files while preserving the folder structure:

- `index.html`
- `assets/css/brain.css`
- `assets/js/brain.js`

Do not replace or delete `config.js`, `recipes.js`, `recipes.css`, `operations.js`, `operations.css`, `modal.js`, SQL files, or logo files.

## Included

- New Atlas Brain navigation page
- Dynamic morning briefing
- Live service countdown using VÁ opening hours
- Readiness, operational risk, recipe risk, data coverage and estimated menu-value-at-risk cards
- Rule-based recommendations from live Inventory, Recipes, Suppliers and Operations data
- Margin-based featured recipe recommendation
- Low-stock intelligence ordered by urgency
- VÁ service timeline
- Rule-based Ask Atlas assistant
- Atlas Brain entry in Service Mode, Quick Actions and Home focus

## Important limitation

Sales history and bookings are not connected yet. Atlas clearly marks those sources as not connected and does not invent demand forecasts.
