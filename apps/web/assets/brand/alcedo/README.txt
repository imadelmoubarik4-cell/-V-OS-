FILES
SVG files are scalable masters with lettering converted to paths.
PNG lockups: 2400 px wide. Transparent versions: logo-color, logo-black, logo-white.
Light and dark versions include backgrounds. White artwork is best viewed on dark backgrounds.
Symbols and app icon: 1024 px. Web icon sizes: 16, 32, 48, 180, 192, 512 px.
favicon.ico: 16/32/48 px. logo-print.pdf: vector RGB print master.
No CMYK conversion or trademark clearance is implied.

PALETTE
Deep teal #08495C / RGB 8 73 92
Orange #E8732A / RGB 232 115 42
Warm ivory #F8F5ED / RGB 248 245 237

USAGE
Use color on ivory/light backgrounds; reversed on teal/dark backgrounds.
Use black or white for single-color production.
Clear space: at least 15% of symbol width around the entire logo.
Recommended minimum lockup width: 180 px / 35 mm.
Use symbol alone below that size; inspect 16/32 px icons in the target interface.
Do not stretch, rotate, rearrange, recolor arbitrarily, or add shadows.
Wordmark is outlined DejaVu Sans with custom tracking; no font install is required.
Keep the reference image as an exploration, not as the production master.
